# DustBox

Windows Forms のファイル消去ツールです。Windows 標準のごみ箱を置き換えるものではなく、このアプリ自体が独立したドロップ先になります。エクスプローラーからこのアプリの領域へファイルやフォルダーをドロップすると、確認後、通常のファイルを暗号学的乱数で1回上書きして削除します。フォルダーは中身を処理してから削除します。再解析ポイントは処理せず、読み取り専用ファイルや上書きに失敗したファイルも削除しません。独自のアイコン画像は `Assets\DustBox.png` と `Assets\DustBox.ico` です。

## 実行

Visual Studio 2022 以降、または .NET 10 SDK がある Windows 環境で、プロジェクトのフォルダーから実行します。

```powershell
dotnet run --project .\DustBox.csproj
```

## ショートカットから使う

ビルド後、`bin\Debug\net10.0-windows\DustBox.exe` を右クリックしてショートカットを作成し、デスクトップなどに配置してください。そのショートカットにエクスプローラーからファイルやフォルダーをドロップすると、アプリが起動して確認ダイアログを表示します。確認後の処理はアプリ画面へのドロップと同じです。

## バージョン情報

`DustBox.csproj` の `Version` を更新すると、EXE/DLL のファイルバージョン（4部形式）と製品バージョン（3部形式）に反映されます。現在は製品バージョン `1.0.0`、ファイルバージョン `1.0.0.0` です。

## 消去に関する注意

これはファイルの通常データ領域を1回上書きするツールであり、消去を保証するものではありません。SSD、コピーオンライトやジャーナリングを使うファイルシステム、クラウド同期、バックアップ、スナップショットでは、上書き前のデータが別の場所に残ることがあります。機密データの消去には、ストレージや OS が提供する適切な消去機能を利用してください。
